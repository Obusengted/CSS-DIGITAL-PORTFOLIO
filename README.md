## Features

- **Glassmorphism design:** frosted-glass cards, soft blur and gentle gradients, with rounded fonts for a smooth but professional look.
- **Easy navigation:** a sticky navigation bar that highlights the current section, a scroll progress bar and a mobile menu.
- **Responsive layout:** works on phones, tablets and desktops.
- **Concise content:** key information up front, with the full reflections available under "Read the full reflection".
- **Interactive elements:** tabbed reflections and letters, photo lightbox, count-up statistics and scroll animations.
- **Downloads:** CV as a PDF, and letters and email as Word documents.
- **Accessibility:** keyboard-friendly controls, descriptive image text and support for reduced-motion settings.

---

## Deploy with GitHub Pages

1. Upload all files to a **public** repository, with `index.html` at the top level and images and the PDF inside the `assets` folder.
2. Go to **Settings**, then **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. After 1 to 3 minutes, your site is live at the address shown on the Pages screen.
